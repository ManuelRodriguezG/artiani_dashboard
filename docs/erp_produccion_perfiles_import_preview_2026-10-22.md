# Preview de importacion de perfiles de peceras y tortugueros

Fecha: 2026-10-22

Fuente: Pedidos Peceras.xlsx

Este documento es un preview read-only. No crea ni modifica registros en la base de datos. Los perfiles se agrupan con los codigos maestros confirmados por el dueno; las medidas conservan las variantes historicas.

## Regla de producto

Los codigos `TORO` representan tortugueros terminados construidos sobre una pecera base `PERA`. No se consideran perfiles independientes de vidrio ni requieren medidas propias para esta fase. La planeacion de vidrio se hace sobre la pecera base; la plataforma o adaptacion para tortuga se fabrica despues.

## Resumen

- Codigos maestros consolidados: 59 (38 PERA y 21 TORO).
- Grupos historicos con filas relacionadas: 36; los grupos `TORO` alimentan perfiles base `PERA` y no se importan como vidrio independiente.
- Perfiles base `PERA` activos despues de la correccion: 38.
- Perfiles base `PERA` sin historial suficiente: 0; tres perfiles fueron reconstruidos con relaciones confirmadas por el dueno.
- Candidatos historicos que no tienen codigo maestro recibido o relacion base confirmada: 8.
- Resultado de activacion: 38 perfiles base `PERA` activos; ningun perfil `TORO` activo como perfil de vidrio.

## Comparacion pendiente por geometria

- `TORO-2040CL`, `TORO-2040CFR` y `TORO-2040CP` tienen medidas parecidas a `TORO-4020`, pero el dueno confirmo que son otro tortuguero; no se relacionan con `PERA-C4020`.
- `TORO-C4040` no coincide exactamente con `PERA-C4040`: conserva un piso cercano, pero cambia la geometria de frontal, lateral y/o respaldo. No se fusiona automaticamente.
- `TORO-CA2040L`, `TORO-CA2040FR` y `TORO-CA2040P` son una variante cercana a la familia C, pero no identica a `PERA-C4040`; se mantienen separados hasta confirmar si representan el mismo producto.
- `TORO-H4040` tiene una configuracion distinta a `PERA-H3850`, por lo que no se asigna automaticamente.

## Criterio de importacion

- No se combinan variantes de medidas en una sola pieza.
- El codigo historico se conserva como alias de origen.
- El codigo maestro sera el identificador visible del perfil.
- El pedido al proveedor se genera con medidas, espesor, cantidades y acomodo; el codigo no sustituye las medidas.
- Los perfiles sin piezas historicas quedan pendientes de completar antes de usarse en un pedido de vidrio. Actualmente no hay perfiles PERA activos en esa condicion.
